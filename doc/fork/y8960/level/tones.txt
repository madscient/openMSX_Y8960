# 音源どうしの音量比を測る音列。実機（tones-mga.ps1）と openMSX（tones.tcl）が同じものを流す。
#
# 書式は 1 行 1 命令。値は 16 進（wait だけ 10 進のミリ秒）。# から行末までは読まない。
#   mem ADDR VAL   カートリッジのスロットのメモリに書く
#   io  PORT VAL   I/O に書く
#   mark LABEL     ここから測る区間が始まる。解析は mark の順に区間を対応づける
#   wait MS        待つ
#
# どの区間も 1 音源の 1ch だけを約 1kHz・最大の音量で鳴らす。ミキサーの音量レジスタは
# リセット値（128）のまま触らない。経路は CANCAN.COM と同じにした（実機で通っている経路）。
#   SSG2: MMIO 7FF0h/7FF1h の R#10h-  OPLL: MMIO 7FF4h/7FF5h  SCC: 9000h=3Fh で 9800h-
#   OPL2: I/O C0h/C1h                  OPM: I/O 7Eh/7Fh（どちらも I/O Enabler2 で開く）
# 前半は定位を中央（リセット値）のまま、後半は左端にして、定位の掛け方も比べる。
# 変調器は AR=0 で黙らせ、FM 音源はキャリア 1 つの正弦波にする。

mem 7FFF 05                 # I/O Enabler2: b0 OPL2、b2 OPM
