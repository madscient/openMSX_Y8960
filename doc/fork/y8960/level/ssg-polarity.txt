# Y8960 の SSG の極性と、ミキサーの音量・定位を書き換えた瞬間の段差を測る音列。実機（tones-mga.ps1 -Sequence）と
# openMSX（tones.tcl、環境変数 Y8960_TONES）が同じものを流し、ssg-polarity.py が比べる。書式は tones.txt と同じ。
#
# 前半（極性）: 4 つの音源を 1 つずつ、上下の向きが読める非対称な波形で鳴らす。録音の経路の反転は 4 つに同じだけ
# 掛かるので、音源どうしの向きの関係は経路に左右されない。周波数はハム（50Hz・60Hz の整数倍）を避けた。
#   SSG2 ch A: トーンもノイズも切り、エンベロープの形 0Ch（上りの鋸歯の繰り返し）。1789772.5 / (256 * 52) = 134.4Hz
#   SCC ch1  : 上りの鋸歯（-128 から 8 ずつ 120 まで）。3579545 / (32 * 832) = 134.4Hz
#   OPLL ch1 : キャリアを半波整流の正弦波（03h の DC）。F-Num 354、BLOCK 2 で 354 * 49716 / 2^17 = 134.3Hz
#   OPL2 ch1 : キャリアを半波の正弦波（01h の bit5 で波形選択を開き、E3h = 1）。F-Num 709、BLOCK 2 で
#              709 * 49716 / 2^18 = 134.5Hz
#
# 後半（段差）: SSG2 ch A を矩形波（998.8Hz、音量 15）と直流（トーンもノイズも切って音量 15）の 2 通りで出し、
# ミキサーの音量（24h）と定位（2Ch）を書き換える。矩形波の区間は、段差の大きさを振れ幅で割るための基準にもなる。
