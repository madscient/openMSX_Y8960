# OPL2 のリズム音と楽音の大きさを比べる音列。書式は tones.txt と同じ。
#
#   tones-mga.ps1 -Sequence rhythm.txt / Y8960_TONES=rhythm.txt で流し、
#   tone-levels.py --seq rhythm.txt --rel bd=ch7-melody --rel tom=ch9-melody --rel sd=ch8-melody で測る。
#
# リズム音と、同じ音色を楽音モードで鳴らした音を、同じスロットの設定で並べて鳴らす。
# 定位は中央（リセット値）、変調器を黙らせた正弦波、約 1kHz。
#   BD : ch7 の 2 演算子。変調器を黙らせるとキャリアの正弦波になり、楽音と同じ波形
#   TOM: ch9 の変調器の正弦波。楽音モードで変調器だけを聞くため、ch9 は CON=1 にしてキャリアを黙らせる
#   SD : ch8 のキャリア。位相がノイズと変調器の位相で決まり、正弦波ではない。基本波だけを比べる。
#        ハードウェア（JTOPL）は変調器の位相の bit8 から作るので変調器の 2 倍の周波数、
#        エミュレーションはキャリア自身の位相から作るのでキャリアの周波数に出る。
#        キャリアの MUL を変調器の 2 倍にして、両方が同じ周波数に出るようにした
#   HH・TC: 正弦波の成分が無く、ハードウェアとエミュレーションで作り方が違う。参考に鳴らすだけ
# 基準に OPL2 ch1 の楽音（tones.txt の opl2-center と同じ音）を最初に置く。
#
# MSX-AUDIO の実チップ（Y8950）でも流せる（tones-mga.ps1 -Target MSXAUDIO）。Y8950 は波形の選択（E0h-F5h）を
# 持たないが、書くのは正弦波の 00h なので結果は変わらない。Y8950 のリズム音の作り方は OPL2 と同じと見ている
# （推測: 同じ OPL の系列の石であることと、openMSX の Y8950 と Y8960OPL2 が同じ式を使っていることだけが根拠）。

only Y8960 mem 7FFF 05      # I/O Enabler2: b0 OPL2、b2 OPM
only MSXAUDIO mem 7FFF 01   # FS-CA1: b0 で C0h/C1h を開く。openMSX の NMS-1205 と HX-MU900 はこの書き込みを捨てる
