# OPLL のリズム音と楽音の大きさを比べる音列。書式は tones.txt と同じ。
#
#   Y8960:  tones-mga.ps1 -Sequence opll-rhythm.txt / Y8960_TONES=opll-rhythm.txt
#   FM-PAC: tones-mga.ps1 -Target FMPAC -Sequence opll-rhythm.txt
#   tone-levels.py --seq opll-rhythm.txt --ref opll-ch1 で測る。
#
# OPLL のリズム音は内蔵の固定の音色で鳴るので、OPL2 の rhythm.txt のように同じ音色の楽音とは比べられない。
# 基準の ch1 の楽音（tones.txt の opll-center と同じ正弦波）との差を、Y8960・実チップ・openMSX で比べる。
# 書き込みは 7FF4h/7FF5h だけ。FM-PAC はこの番地への書き込みが I/O の有効化（7FF6h）なしで効く
# （openMSX の MSXFmPac.cc のコメントと実装）。
# リズム音の周波数は ch7-9 とも F-Num 330、BLOCK 5。音量は 36h-38h を 0（最大）。
# HH・SD・TC はノイズと位相で決まり正弦波ではないので、基本波の値は目安。RMS も並べて見る。

# --- 準備（まだ鳴らさない） ---

mem 7FF4 0E                 # 楽音モード
mem 7FF5 00

# ch1: ユーザー音色。キャリアは MUL 1、持続、AR 15、SL 0、RR 15。変調器は AR 0。

mem 7FF5 0B
